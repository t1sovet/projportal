Class Usage & Code Examples

Instruction-focused examples for key classes (8 classes).

1) services.UniversityDatabase

Use as the shared state holder. Access through its singleton accessor only.

  • Do: store/retrieve users, courses, requests here.
  • Do not: create ad hoc in-memory lists in menu classes.
import services.UniversityDatabase;

UniversityDatabase db = UniversityDatabase.getInstance();
// Example: db.addUser(student);
// Example: db.addCourse(course);

2) services.AuthService

Use for login/logout and event notifications. Keep credential checks inside this service.

import services.AuthService;
import services.UniversityDatabase;
import models.User;

AuthService auth = new AuthService(UniversityDatabase.getInstance());
try {
    User user = auth.login("student@projportal.kz", "1234");
    // route by user.getUserType()
} catch (Exception e) {
    System.out.println("Login failed: " + e.getMessage());
}

3) models.Student

Use Student for course registration and personal academic state. Registration must enforce credit/fail limits.

import models.Student;
import models.Course;
import exceptions.CreditLimitExceededException;
import exceptions.FailLimitExceededException;

Student s = new Student("S001", "Aruzhan", "a@uni.kz", "pwd", null);
Course oop = new Course("CS101", "OOP", 5);

try {
    s.registerCourse(oop);
} catch (CreditLimitExceededException | FailLimitExceededException ex) {
    System.out.println(ex.getMessage());
}

6) services.ResearchService

Use this service for cross-user research operations and sorting utilities.

7) utils.DataStorage

Use DataStorage to persist and restore university state from serialized storage.

import utils.DataStorage;
import services.UniversityDatabase;

UniversityDatabase db = UniversityDatabase.getInstance();
DataStorage.save(db, "db.ser");
UniversityDatabase restored = DataStorage.load("db.ser");

8) utils.UserFactory

Use UserFactory when creating users by role to avoid duplicated construction logic.

import utils.UserFactory;
import enums.UserType;
import models.User;

User u = UserFactory.createUser(
    UserType.STUDENT,
    "S010",
    "Nursultan",
    "n@uni.kz",

);
System.out.println(u.getName());

General Guidance

  • Catch domain exceptions at menu/service boundaries and print actionable messages.
  • Prefer method calls across interfaces instead of type-check chains where possible.
  • Keep object creation centralized in factory/service layers for consistent defaults.
