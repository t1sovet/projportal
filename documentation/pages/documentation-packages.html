ProjPortal Package Map

Package-level structure for src with responsibility boundaries.

Package Responsibility Main files
demo Console UI flows and role menus only. Main.java, AdminMenu.java, ManagerMenu.java, TeacherMenu.java, StudentMenu.java, ResearchEmployeeMenu.java, DeanRectorMenu.java, ConsoleUtils.java
models Domain entities and business state. User.java, Employee.java, Student.java, Teacher.java, Manager.java, Admin.java, Dean.java, Rector.java, Course.java, Lesson.java, Mark.java, ResearchPaper.java, ResearchProject.java, RegistrationRequest.java, EmployeeRequest.java, Message.java, Complaint.java, NewsItem.java, ResearchEmployee.java
services Cross-entity workflows and orchestration. UniversityDatabase.java, AuthService.java, ResearchService.java, ResearcherDecorator.java
interfaces Behavior contracts and extension points. Observable.java, Observer.java, Printable.java, Researcher.java, ReportStrategy.java
utils Infrastructure and technical helpers. DataStorage.java, SystemLogger.java, UserFactory.java, SimpleStatisticsStrategy.java
enums Type-safe constants and statuses. UserType.java, DegreeType.java, TeacherTitle.java, ManagerType.java, RequestStatus.java, LessonType.java, SchoolType.java, WeekDays.java
exceptions Domain-specific rule violations. AuthenticationException.java, CreditLimitExceededException.java, FailLimitExceededException.java, CourseNotTaughtException.java, StudentNotEnrolledException.java, NotResearcherException.java, LowHIndexException.java

Boundary Rule

demo should call services/models but should not contain domain rules. services may coordinate models. models should not depend on demo.
